Eat Orange - Android Studio Project (WebView wrapper)
---------------------------------------------------
This project wraps the HTML prototype in a simple Android WebView so you can build an installable APK.

How to build:
1. Install Android Studio (recommended).
2. Open this folder as a project in Android Studio.
3. Let it sync Gradle; accept any prompts to install SDK components.
4. Connect an Android device or use an emulator.
5. Run the project (Run > Run 'app') to install the APK on device / emulator.
6. To generate a signed APK for distribution: Build > Generate Signed Bundle / APK.

Notes:
- The HTML game file is located at app/src/main/assets/eat_orange.html
- You can edit the HTML/JS/CSS directly and rebuild.
- If you want a more native experience, I can convert logic into Kotlin/Java or provide a Unity project.
